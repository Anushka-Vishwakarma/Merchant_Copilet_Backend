# PHASE 15 — Prevent data leakage

This is **very important**.

Suppose:

```text
Order placed
     ↓
Prediction
     ↓
RTO happens
```

The model can use information available **before prediction**.

It cannot use:

```text
rto_happened = true
```

as an input to predict RTO.

Correct:

```text
Information before prediction
             ↓
          Features
             ↓
         Prediction
             ↓
        Actual outcome
```

Your project specifically requires point-in-time features and FeatureSnapshot records to preserve this distinction.
