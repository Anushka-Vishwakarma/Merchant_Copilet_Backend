## The key thing you're building on Days 2–4

You need an **adapter architecture**:

```text
Shopify
   ↓
Shopify Adapter
   ↓
                  ┌──────────────────────┐
                  │ Common Data Model    │
                  │                      │
                  │ Customer             │
                  │ Order                │
                  │ OrderItem            │
                  │ Product              │
                  │ Payment              │
                  │ Fulfillment          │
                  │ Refund               │
                  └──────────┬───────────┘
                             ↓
                         PostgreSQL
                             ↑
                  ┌──────────┴───────────┐
                  │ Common Data Model    │
                  └──────────┬───────────┘
                             ↑
                    WooCommerce Adapter
                             ↑
                       WooCommerce
```

This is **very important**.

You don't want your ML/analytics code saying:

```text
if Shopify:
    use Shopify field
else:
    use WooCommerce field
```

everywhere.

Instead:

```text
Shopify ──→ Adapter ──→ Common Model
WooCommerce ──→ Adapter ──→ Common Model
```

Then your analytics works on the common model.
